# CTF Write-ups

A collection of my write-ups for Capture The Flag (CTF) challenges across web, crypto, forensics, reverse engineering, pwn, and miscellaneous categories. Each write-up documents my thought process, the tools I used, and the steps to reach the flag, with the goal of learning in public and helping others who are getting started.

## About

I'm Kenji Flores, a student interested in cybersecurity. I started playing CTFs to build practical skills, and this repository is where I keep notes on the challenges I solve.
